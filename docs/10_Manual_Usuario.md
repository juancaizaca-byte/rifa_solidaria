# 📘 Manual de Usuario - Sistema de Rifa 

## 1. Introducción
Este manual explica cómo utilizar el sistema de rifa desde la perspectiva de los distintos actores: 
**compradores, vendedores y administradores**.  
El objetivo es guiar al usuario en cada paso para garantizar una experiencia clara y sencilla.

---

## 2. Acceso al sistema
- El sistema está disponible en línea a través de la URL oficial:  
  **https://rifasolidaria.streamlit.app**  
- No requiere instalación en el dispositivo del usuario.  
- Compatible con navegadores modernos (Chrome, Edge, Firefox).

---

## 3. Uso para Compradores
### 3.1 Selección de boletos
1. Ingresar al enlace recibido del vendedor.  
2. Visualizar los boletos disponibles (color verde).  
3. Seleccionar el número deseado.  
4. Confirmar la compra o reserva.  

### 3.2 Comprobante PDF
- Tras la confirmación, el sistema genera un **comprobante en PDF** con:  
  - Datos del comprador.  
  - Número de boleto.  
  - Código QR de validación.  
- El comprador puede descargar y guardar el comprobante.

---

## 4. Uso para Vendedores
### 4.1 Registro de venta
1. Acceder al formulario de vendedor.  
2. Ingresar datos del comprador (nombre, teléfono).  
3. Seleccionar cantidad de boletos.  
4. Confirmar la venta.  
5. El sistema genera un enlace único para el comprador.

---

## 5. Uso para Administradores
### 5.1 Reportes
- Acceder al módulo de reportes.  
- Visualizar boletos por estado: vendidos, reservados, disponibles.  
- Exportar reporte en PDF o Excel.  

### 5.2 Validación de boletos *(pendiente de implementación)*
- El administrador podrá ingresar el número de boleto y verificar su validez.  
- Estado posible: válido, reservado, inválido.  
- Esta función se encuentra planificada para futuras versiones.
